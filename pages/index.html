한밤의 늑대인간 - MidnightWolf

친구들과 실시간으로 즐기는 웹 버전 프로젝트

도플갱어 하수인 프리메이슨 사냥꾼 실시간 Socket.IO

안내

이 GitHub Pages는 프로젝트 소개 페이지입니다. 실제 게임 플레이는 Node 서버 실행이 필요합니다.

GitHub 저장소 열기

로컬 실행

  1. git clone https://github.com/wndzlf/MidnightWolf.git
  2. cd MidnightWolf
  3. npm install
  4. npm run dev
  5. 브라우저에서 http://localhost:3000 접속
